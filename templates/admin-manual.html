管理员操作手册

1. 进入管理页

  1. 浏览器访问 http://<盒子IP>:9203/admin（首页导航不放入口，需手动输入地址）。
  2. 首次访问会引导设置 PIN 码（至少 4 位），之后每次访问需输入。连续输错 5 次锁定 60 秒。
  3. 忘记 PIN：删除服务目录下 admin_config.json 后重启服务，重新设置。

2. 宿主机资源监控

  • 显示 CPU 使用率、CPU 温度、内存、磁盘占用（系统盘 + 扫描目录所在盘），每 30 秒自动刷新。
  • 温度读取：优先读海思机顶盒的 /proc/msp/pm_cpu，通用 Linux 回退 /sys/class/thermal。

3. 环境 / 依赖检测

  • 自动检测 Python、SANE（scanimage）、ImageMagick（convert）、Pillow 版本。
  • 检查服务用户是否已加入 lp / scanner 组（未加入则无法访问 USB 扫描仪）。
  • 检查扫描存储目录是否存在且可写。

4. 扫描设备管理

  1. 设备列表：自动探测已连接的扫描仪（5 分钟缓存，点「重新探测」强制刷新）。
  2. 测试扫描：真实扫一页验证设备工作正常，生成一个「测试扫描」任务。
  3. 设备别名：给设备设一个好记的名字，扫描页面将显示别名。
  4. 扫描默认值：每台设备可独立设置默认 DPI、色彩模式、是否裁边。DPI 和色彩选项来自设备真实能力。保存后刷新扫描页即生效，用户创建任务时仍可自行修改。

5. 扫描存储位置

  • 默认 /opt/smb_share/scans。修改后立即生效，无需重启服务。
  • 输入不存在的路径会提示确认，确认后自动创建。

6. 历史记录自动清理

  • 三项策略可任意组合（填 0 表示不启用）：任务数上限 / 保留天数 / 总占用 MB。
  • 任意一条超限即从最旧任务开始删除。服务启动时、每小时、保存配置时各执行一次。
  • 带 🔒 锁定的任务永远不会被清理——重要任务请先锁定。

7. 历史任务管理

  • 查看全部任务的页数、大小、创建时间。
  • 「锁定」可切换 🔒 状态：锁定任务不被自动清理、不可删除。
  • 「删除」需二次确认；锁定任务的删除按钮禁用。

8. 附录：手动查看设备命令

SSH 登录盒子后执行（以下命令均需以 scanops 服务用户身份运行，验证与实际服务一致的权限）：

# 列出所有已连接的扫描仪
sudo -u scanops scanimage -L

# 查看某台设备的完整参数（分辨率、色彩模式、扫描区域、ADF 等）
sudo -u scanops scanimage -d "hpljm1005:libusb:001:003" -A

# 用第一台设备实际扫一页测试（输出 PNM 数据到文件）
sudo -u scanops scanimage -d "hpljm1005:libusb:001:003" \
  --format=pnm --mode Gray --resolution 150 > /tmp/test.pnm

# 查看 USB 设备节点权限（服务用户需在 lp 组）
ls -l /dev/bus/usb/001/

说明：设备名中 libusb:001:003 部分是 USB 总线号，重启或换 USB 口后可能变化；系统内部会自动解析完整设备名，无需手动固定。

9. 附录：手动检查依赖命令

# 检查 scanimage 是否安装
which scanimage && scanimage --version

# 检查 ImageMagick convert 是否安装
which convert && convert --version

# 检查 Python 虚拟环境依赖（flask / waitress / Pillow / qrcode）
/opt/network_scan_service/.venv/bin/python -c "import flask, waitress, PIL; print('OK')"

# 检查服务用户与组（应包含 lp 和 scanner）
id scanops

# 检查服务状态
systemctl status networkscan --no-pager

# 查看服务日志
journalctl -u networkscan -n 50 --no-pager

缺失依赖的安装方法（ARM32 需源码编译，详见项目 README 第三步）：

apt install -y sane-utils imagemagick      # scanimage + convert
cd /opt/network_scan_service
uv pip install --index-url https://pypi.tuna.tsinghua.edu.cn/simple \
  flask waitress "pillow>=7.0,<9" qrcode

10. 附录：服务管理（webscan 命令）

webscan status              # 服务状态 + 版本 + HTTP 响应
webscan update              # 一键更新（自动检测目录下的更新包）
webscan restart             # 重启服务
webscan stop                # 停止服务
webscan start               # 启动服务
webscan logs 100             # 查看最近 100 行日志
webscan version             # 查看当前版本

11. 常见问题

  • 管理页不停刷新：旧版本已知问题（v1.13 已修复），若仍出现请升级到最新版。
  • 探测不到设备：先手动执行附录 8 的命令确认权限；检查 USB 线和扫描仪电源。
  • 设备能力显示"未知"：点「重新探测」；仍失败查看日志中 scanimage -A 的报错。
  • 测试扫描报"设备忙"：有人在扫描中，等当前扫描完成后再试。
  • CPU 温度显示"无传感器"：非海思设备且系统无 thermal_zone 时的正常现象。
