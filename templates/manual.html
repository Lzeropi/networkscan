操作手册

1. 创建扫描任务

  1. 在首页"新建扫描任务"卡片中，输入备注（选填，如"验收单"），备注会出现在任务文件夹名中。
  2. 如需按 A4 尺寸裁边，勾选"按 A4 尺寸裁边"。
  3. 点击"创建并开始"按钮，系统自动创建任务并跳转到任务详情页。

2. 高级选项（选填）

点击"高级选项"可展开更多设置：

  • 扫描方式：默认为平板单张扫描。如果扫描仪支持自动进纸器（ADF），会自动显示"连续进纸"选项。系统会自动探测设备能力，不支持的功能会自动隐藏。
  • 分辨率：150 dpi（日常文档，速度快、文件小）、300 dpi（清晰文档，推荐）、600 dpi（高精度图片，文件较大）。
  • 色彩：系统会根据设备能力自动显示可用的模式，不支持的会自动隐藏。
    • 彩色：保留完整色彩信息，适合扫描彩色照片、带红章的文件。文件最大。
    • 灰度：将颜色按亮度转为 256 级灰阶，保留深浅层次，适合日常文档。文件适中，推荐使用。
    • 黑白：纯黑白二值图像，无灰色过渡——有内容处为黑色，空白处为白色。适合纯文字扫描，文件最小。仅在设备支持时显示。
  • 设备：自动列出已连接的扫描仪，默认使用第一台。

3. 扫描操作

平板扫描（单页）

  1. 在任务详情页点击"扫描单页"按钮。
  2. 等待 10–30 秒，扫描完成后缩略图自动出现在图墙中。
  3. 可重复点击继续扫描下一页，每次扫描一页。

ADF 连续扫描（需设备支持）

  1. 将整叠纸放入自动进纸器。
  2. 点击"开始连续扫描"按钮，系统后台执行批量扫描。
  3. 页面每 1.5 秒自动刷新进度，显示"已扫 N 页"。
  4. 扫描完成后页面自动刷新，所有页面出现在图墙中。

4. 调整页面顺序

扫描时若纸张顺序与真实顺序不一致（如先扫了最后一页），无需重扫，可直接在网页上拖拽调整：

  1. 在任务详情页，当任务有 2 页以上时，图墙右上角出现「调整顺序」按钮。
  2. 点击进入排序模式，每张缩略图左上角显示当前序号（1、2、3…）。
  3. 进入排序模式后默认为拖拽模式：按住图片拖动，哪张图片亮起蓝色边框，松手后就放置到哪张图的位置（占位），其余页面自动顺延补位。
  4. 控制栏有「按钮排序」开关：点击后每张图右上角显示「←」「→」箭头按钮，点一下即可前后移动一位（适合触屏设备）；再点开关可关回纯拖拽模式。
  5. 依次调整完所有页后，点击「保存顺序」，系统会按新顺序重排页面文件，之后的 ZIP / PDF 下载均按新顺序合并。
  6. 点击「取消」放弃本次调整。

提示：保存后页名仍为 p001、p002…（系统按新顺序重新编号），缩略图内容即为调整后的顺序。ZIP / PDF 下载均按新顺序合并。默认拖拽模式界面简洁；触屏设备点「按钮排序」开关即可。

5. 查看与下载

  • 查看大图：点击图墙中任意缩略图，弹出灯箱预览，点击空白处关闭。
  • 下载单页：缩略图下方 ⬇ 按钮下载该页原图 PNG。
  • 打包 ZIP：下载所有页面的原图，打包为 ZIP 文件。
  • 合成 PDF：将所有页面合并为一份 PDF 文件。超过 20 页时为防止设备内存不足，请改用 ZIP 下载。
  • 扫码取件：点「📱 扫码取件」弹出二维码，手机扫码直接打开本任务页，无需手动输入地址。

6. 删除任务

  1. 在任务详情页点击"删除任务"按钮。
  2. 弹出确认窗口，点击"确定"删除。
  3. 扫描进行中不允许删除，需等待扫描完成。

7. 历史任务

首页下方"历史任务"区域展示所有扫描任务，按时间倒序排列。每张卡片显示首页缩略图、任务名、创建时间和页数。点击卡片进入任务详情页。

8. 自动清理

清理策略在管理页（/admin）配置：任务数 / 保留天数 / 总占用 MB 三项可任意组合（填 0 表示不启用），任意一条超出限制即从最旧任务开始删除；带 🔒 锁定的任务永远不会被清理。服务启动时、每小时、保存配置时各执行一次。

9. 常见问题

  • 扫描报错：检查扫描仪是否开机、USB 是否连接、服务用户是否有设备访问权限。
  • 找不到设备：确认扫描仪已连接，检查服务用户是否在 lp/scanner 组中。
  • 页面提示"依赖检查"：系统缺少 scanimage 或 convert 命令，按提示安装。
  • PDF 合成失败：页面数超过 20 页限制，请改用 ZIP 下载。
  • 拖拽排序无效：触屏设备请点控制栏「按钮排序」开关，用箭头按钮移动；电脑浏览器默认拖拽即可。
  • 提示“设备忙”：局域网内有人正在扫描，扫描仪为独占设备，请等待当前扫描完成后再试。
